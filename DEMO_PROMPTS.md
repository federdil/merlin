# Merlin Demo Prompts

Curated prompts to showcase Merlin v2.0's capabilities during demonstrations. Organized by functionality to highlight the Strands Agents architecture and intelligent routing system.

## 🎯 Basic Knowledge Management

### 1. Content Ingestion & Organization
```
"I just read an article about transformer architectures in deep learning. Can you help me organize this knowledge?"
```

### 2. Knowledge Retrieval & Search
```
"What do I know about machine learning from my previous readings?"
```

### 3. Knowledge Summarization
```
"Can you summarize my understanding of artificial intelligence based on my notes?"
```

## 🧠 Advanced Learning Features

### 4. Knowledge Gap Analysis

### 5. Learning Path Generation

## 📝 Demo Tips

- Start with simple ingestion to populate the knowledge base
- Show the conversational nature by building on previous queries
- Demonstrate cross-domain connections (movies + AI, books + technology, food + culture)
- Highlight the learning path generation and knowledge gap analysis
- Show how the system maintains context across conversations
- Use the movie, book, and recipe examples to make it relatable and engaging
- Showcase the diverse content types: AI/philosophy, romantic/comedy movies, Italian cuisine
- Demonstrate how the system can connect seemingly unrelated topics (e.g., cooking principles to life philosophy)
